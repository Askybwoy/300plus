# Telegram Bot Audit Scenario - 300.plus

## Обзор

Пользователь заполняет форму на сайте 300.plus, попадает в Telegram-бот `@its300plus_bot`, проходит 6 быстрых вопросов (inline-кнопки, без набора текста), отправляет ссылку на сайт. Система делает скриншот, анализирует через Claude AI с учётом ответов, генерирует PDF-отчёт и отправляет результат в Telegram.

```
САЙТ 300.plus ──[форма]──> WEBHOOK ──> TELEGRAM BOT
                                            │
                                      Приветствие
                                            │
                                      Q1: Цель (4 варианта)
                                      Q2: Ниша (7 вариантов)        ← НОВЫЙ
                                      Q3: Аудитория (4 варианта)     ← НОВЫЙ
                                      Q4: Трафик (4 варианта)        ← НОВЫЙ
                                      Q5: Стадия (3 варианта)
                                      Q6: Готовность (3 варианта)    ← обновлён
                                            │
                                      [URL если нет]
                                            │
                                      Одобрение владельца
                                            │
                            ┌───────────────┴───────────────┐
                        Одобрено                        Отклонено
                            │                               │
                   ScreenshotOne → Claude AI         "Попробуйте позже"
                            │
                   Текст-сводка → Telegram
                   PDF-отчёт → Telegram
                   Персональный оффер
```

**Время прохождения**: ~60-90 секунд (все кнопки, текст только при вводе URL).

---

## 1. Точки входа с сайта

Пользователь заполняет форму (Modal). Webhook отправляет `{ name, contact, url, form }`.
Поле `form` определяет бонус к lead score:

| Источник формы | Бонус |
|---|---|
| "Запустить спринт" | +4 |
| "Обсудить проект" / "Запустим ваш проект" | +3 |
| "Заказать аудит" | +2 |
| "Бесплатный аудит" / "Расскажите о вашей идее" | +1 |

## 2. Приветствие

```
👋 Привет, {name}!

Я — бот 300.plus. Проведу экспресс-аудит вашего сайта
и покажу точки роста конверсии.

Чтобы аудит был максимально полезным, задам 6 быстрых
вопросов. Это займёт буквально минуту 🕐
```

| Кнопка | callback_data |
|---|---|
| 🚀 Начать | `step0_start` |
| ❓ Что я получу? | `step0_what` |

При нажатии "Что я получу?" — отправляется объяснение:

```
🔍 Что такое экспресс-аудит?

Мы анализируем ваш сайт с помощью ИИ и находим точки роста конверсии.
Вы получите PDF-отчёт с конкретными рекомендациями.

✅ Бесплатно
✅ Занимает 2-3 минуты
✅ Конкретные гипотезы с потенциалом роста
```

Затем переход к Q1.

## 3. Вопросы (Q1–Q6)

### Q1 — Цель

> 📋 Какая главная задача для вашего сайта сейчас? (1/6)

| Кнопка | callback_data | Score | Фокус Claude |
|---|---|---|---|
| 📈 Больше заявок | `goal_leads` | +3 | CTA, формы, воронка конверсии |
| 🤔 Не конвертит | `goal_convert` | +3 | Первый экран, УТП, доверие |
| 🎨 Нужен редизайн | `goal_redesign` | +2 | Визуал, UX-паттерны, современность |
| 👀 Просто интересно | `goal_curious` | +0 | Общий обзор |

**Микро-реакция**: "Понял! 👍"

---

### Q2 — Ниша (НОВЫЙ)

> 🏷 В какой сфере ваш бизнес? (2/6)

| Кнопка | callback_data | Score |
|---|---|---|
| 🛍 E-commerce / Магазин | `niche_ecom` | +1 |
| 💼 Услуги / B2B | `niche_b2b` | +2 |
| 🎓 Обучение / EdTech | `niche_edu` | +1 |
| 🏥 Медицина / Здоровье | `niche_med` | +2 |
| 🍔 HoReCa / Еда | `niche_horeca` | +1 |
| 💻 IT / SaaS | `niche_it` | +2 |
| 🔧 Другое | `niche_other` | +1 |

**Зачем Claude**: Отраслевые бенчмарки. Для B2B — акцент на кейсы и ROI-цифры. Для e-commerce — страницы товаров и checkout. Для медицины — доверие и сертификации.

**Микро-реакция**: "Хорошо, учту специфику 👌"

---

### Q3 — Аудитория (НОВЫЙ)

> 👥 Кто ваш основной клиент? (3/6)

| Кнопка | callback_data | Score |
|---|---|---|
| 👤 Обычные люди (B2C) | `aud_b2c` | +1 |
| 🏢 Бизнес / компании (B2B) | `aud_b2b` | +2 |
| 👤+🏢 И те, и другие | `aud_both` | +1 |
| 🤷 Пока определяюсь | `aud_unsure` | +0 |

**Зачем Claude**: B2C — оценка эмоционального вовлечения и скорости. B2B — убедительность, соц. доказательства, глубина контента.

---

### Q4 — Трафик (НОВЫЙ)

> 📊 Сколько примерно посетителей у сайта в месяц? (4/6)

| Кнопка | callback_data | Score |
|---|---|---|
| 🌱 Меньше 500 | `traffic_low` | +0 |
| 📈 500 – 5 000 | `traffic_mid` | +2 |
| 🚀 5 000 – 50 000 | `traffic_high` | +3 |
| 🔥 Больше 50 000 | `traffic_mega` | +4 |

**Зачем Claude**: При высоком трафике — приоритет на quick wins с макс. CR-потенциалом. При низком — фокус на базовые ошибки.

**Микро-реакция** (traffic_high/mega): "Серьёзный объём! С таким трафиком каждый процент конверсии — это деньги 💰"

---

### Q5 — Стадия

> 🏢 На какой стадии ваш проект? (5/6)

| Кнопка | callback_data | Score |
|---|---|---|
| 🚀 Запускаемся | `stage_startup` | +1 |
| 📊 Растём | `stage_growth` | +3 |
| 🏢 Масштабируемся | `stage_scale` | +4 |

**Зачем Claude**: Стартап — ясность предложения. Рост — оптимизация воронки. Масштаб — тонкая настройка, A/B-тесты.

### Q6 — Готовность к действию (обновлён)

> 💡 Если аудит покажет точки роста — готовы действовать? (6/6)

| Кнопка | callback_data | Score |
|---|---|---|
| ✅ Да, хочу расти | `ready_yes` | +5 |
| 🤔 Зависит от рекомендаций | `ready_maybe` | +3 |
| 👀 Пока только смотрю | `ready_no` | +0 |

Формулировка мягче старой "Готовы инвестировать?" — не отпугивает.

**Микро-реакция**: "Отлично, у меня всё для аудита! 🎯"

## 4. Сбор URL

После Q6, если `projectUrl` не пришёл с формы:

```
🌐 Осталось последнее — отправьте ссылку на ваш сайт:
```

Тип: `sendAndWait`, свободный текст, таймаут 24 часа.
Валидация: если текст не похож на URL — переспросить: "Хм, это не похоже на ссылку. Пришлите URL вида example.com"

Если URL уже есть — этот шаг пропускается.

## 5. Lead Scoring

### Формула

```
Total = entry_bonus + Q1 + Q2 + Q3 + Q4 + Q5 + Q6
```

### Классификация

| Диапазон | Тип лида | Стратегия оффера |
|---|---|---|
| **18–24** | 🔥 HOT | Агрессивный: "Пакет СПРИНТ, 7 дней, 90 000 руб" |
| **10–17** | 🟡 WARM | Мягкий: "Бесплатная 30-мин консультация" |
| **0–9** | 🔵 COLD | Пассивный: "Сохраните отчёт, мы рядом" |

Максимум: 24 (Sprint entry + leads + B2B niche + B2B aud + mega traffic + scale + ready).
Минимум: 3 (audit entry + curious + other niche + unsure aud + low traffic + startup + looking).

## 7. Обогащённый промпт Claude AI

Текущий промпт — generic. Новый промпт использует ВСЕ 6 ответов:

```
Ты — старший UX/конверсионный аналитик студии 300.plus.

КОНТЕКСТ КЛИЕНТА:
• Ниша: {niche_label}
• Целевая аудитория: {audience_label}
• Главная задача: {goal_label}
• Месячный трафик: {traffic_label}
• Стадия бизнеса: {stage_label}
• Готовность к изменениям: {ready_label}

ЗАДАЧА:
Проанализируй скриншот главной страницы сайта {url}.
Учитывай нишу клиента и его аудиторию при оценке.
Фокусируйся на: {focus_area}.

Ответ — строго JSON:
{
  "overall_score": 5.6,
  "total_potential": "+75% CR",
  "executive_summary": "Краткий вердикт в 2-3 предложения",
  "scores": [
    {"label": "Первый экран", "score": 6, "comment": "Пояснение"},
    {"label": "Ясность предложения", "score": 7, "comment": "..."},
    {"label": "CTA и формы", "score": 4, "comment": "..."},
    {"label": "Доверие и соц.доказательства", "score": 5, "comment": "..."},
    {"label": "Мобильная версия", "score": 6, "comment": "..."}
  ],
  "issues": [
    {
      "number": 1,
      "title": "Название проблемы",
      "problem": "Описание с учётом ниши",
      "hypothesis": "Гипотеза для A/B теста",
      "solution": "Конкретное решение",
      "priority": "высокий",
      "complexity": "низкая",
      "potential": "+20% CR",
      "comment": "Комментарий эксперта"
    }
    // ... 5 issues total
  ],
  "quick_wins": [
    "Действие 1 (можно за час)",
    "Действие 2 (можно за час)",
    "Действие 3 (можно за час)"
  ]
}
```

### Маппинг goal → focus_area

| Goal | Focus Area |
|---|---|
| leads | Анализ CTA-элементов, форм захвата, пути до конверсии, убедительности оффера |
| convert | Первый экран, ясность УТП, факторы доверия, барьеры конверсии |
| redesign | Визуальная современность, UI-паттерны, UX-flow, сравнение с лидерами ниши |
| curious | Общий обзор всех аспектов с приоритизацией по потенциалу роста |

### Новые поля в ответе Claude (vs текущая реализация)

- `executive_summary` — краткий вердикт для текстового сообщения
- `scores[].comment` — пояснение к каждой оценке (для PDF)
- `quick_wins` — 3 действия, которые можно сделать за час

📄 Полный PDF-отчёт с деталями ↓

| Страница | Содержание |

## 9. Технические детали

### Объект состояния пользователя

```json
{
  "chatId": "string",
  "name": "string",
  "contact": "string",
  "projectUrl": "string",
  "formSource": "string",
  "goal": "leads | convert | redesign | curious",
  "niche": "ecom | b2b | edu | med | horeca | it | other",
  "audience": "b2c | b2b | both | unsure",
  "traffic": "low | mid | high | mega",
  "stage": "startup | growth | scale",
  "readiness": "yes | maybe | no",
  "leadScore": "number (0-24)",
  "leadType": "hot | warm | cold",
  "step": "number (0-6)",
  "ts": "ISO timestamp"
}
```

### Router Prefixes

| Шаг | Prefix | Примеры callback_data |
|---|---|---|
| 0 | step0 | step0_start, step0_what |
| 1 | goal | goal_leads, goal_convert, goal_redesign, goal_curious |
| 2 | niche | niche_ecom, niche_b2b, niche_edu, niche_med, niche_horeca, niche_it, niche_other |
| 3 | aud | aud_b2c, aud_b2b, aud_both, aud_unsure |
| 4 | traffic | traffic_low, traffic_mid, traffic_high, traffic_mega |
| 5 | stage | stage_startup, stage_growth, stage_scale |
| 6 | ready | ready_yes, ready_maybe, ready_no |

### Обработка ошибок

| Ситуация | Решение |
|---|---|
| Пользователь бросил на середине | Состояние хранится в staticData, при возврате продолжает с того же шага |
| ScreenshotOne не ответил | Уведомление владельцу "Скриншот не удался", ручной retry |
| Claude вернул не-JSON | Fallback: regex-извлечение JSON, дефолтные оценки |
| URL без протокола | Автоматическое добавление https:// |
| Текст вместо URL | Переспросить: "Пришлите ссылку вида example.com" |
