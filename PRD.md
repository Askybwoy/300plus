# 300.plus — Product Requirements Document

## 1. Общая информация

### 1.1 Название продукта
300.plus — студия быстрого тестирования бизнес-идей

### 1.2 Слоган
**Ваш спринт-отдел в кризис**

### 1.3 Цель продукта
Помочь маркетологам крупных компаний проверить гипотезы за 7 дней через создание бренда, лендинга и запуск таргетированной рекламы — без найма, без долгих согласований, без риска масштабных инвестиций.

### 1.4 Целевая аудитория
- **Стартаперы** — с идеей, но без ресурсов на полноценный запуск
- **Малый бизнес** — хотят протестировать новое направление/продукт
- **Маркетологи/продакт-менеджеры** — внутри компаний, нужен быстрый MVP
- **Средний бизнес** — запуск новых продуктовых линеек

### 1.5 Ключевая метрика успеха для клиента
Количество заявок/лидов — главный показатель эффективности тестирования идеи.

## 2. Продуктовое предложение

### 2.1 Основное предложение (Value Proposition)
**Ваш спринт-отдел в кризис**

Альтернативные формулировки для разных блоков сайта:
- "Запускайте гипотезы за неделю, а не за квартал"
- "Неделя вместо квартала. Пока другие думают — вы знаете"
- "Сгорите за 300 тысяч, а не за 3 миллиона"
- "Ваш спринт-отдел, когда нет времени ждать"
- "300 тысяч вместо 3 миллионов на тест"

### 2.2 Что входит в пакет (300 000 ₽)
| Этап | Срок | Результат |
|------|------|-----------|
| Интервью | День 1 | Погружение в проект, фиксация гипотез |
| Предоплата | День 1-2 | 150 000 ₽, старт работ |
| Бренд + лендинг | День 2-5 | Айдентика, посадочная страница |
| Запуск рекламы | День 6-7 | Таргет, первые заявки |

### 2.3 Дополнительные услуги
- **Бесплатный аудит** — разбор чужого сайта с видео-разбором
- **Поддержка после запуска** — доработка и масштабирование при успехе

## 3. Функциональные требования

### 3.1 Структура сайта (одностраничный лендинг)

#### 3.1.1 Hero-секция
- **Заголовок**: "Проверим вашу идею за 7 дней"
- **Подзаголовок**: стоимость и краткое описание включённых услуг
- **3 CTA-карточки** (точки входа):
  1. "У меня только идея" — воронка для новых проектов
  2. "Есть бренд, нужен запуск" — воронка для обновления
  3. "Бесплатный аудит" — лид-магнит

#### 3.1.2 Секция "Как это работает"
- 4 шага с таймингом
- Визуальная связь между этапами
- Итоговый CTA: запись на интервью

#### 3.1.3 Секция "Что вы получаете"
- 6 ключевых преимуществ
- Карточка с ценой (300 000 ₽)
- Две кнопки: "Обсудить проект" / "Бесплатный аудит"

#### 3.1.4 Секция Moodboard/Референсы
- Демонстрация современных трендов дизайна
- Блок "Психология внимания"
- Блок "Технологии" (стек)

#### 3.1.5 Секция "Аудит конкурентов"
- Форма с полями: URL сайта, Email
- Описание процесса (3 шага)
- Состояние успешной отправки

#### 3.1.6 FAQ
- 6 частых вопросов (аккордеон)
- Ссылка на Telegram для дополнительных вопросов

#### 3.1.7 Footer
- Логотип
- Описание услуги
- Контакты (Telegram, Email)
- Копирайт

### 3.2 Модальные окна

#### 3.2.1 Модальное окно заявки
Поля формы:
- Имя (обязательное)
- Контакт (Telegram или Email, обязательное)
- Описание проекта (опциональное)

Состояния:
- Форма ввода
- Отправка (loader)
- Успешная отправка (confirmation)

Типы модальных окон (зависят от CTA):
- Для "У меня только идея"
- Для "Есть бренд, нужен запуск"
- Для "Бесплатный аудит"

### 3.3 Навигация
- Плавный скролл к секциям
- Фиксированная кнопка связи (опционально)

## 4. Нефункциональные требования

### 4.1 Технологический стек
- **Framework**: Next.js 14+ (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **UI Library**: shadcn/ui (базовые компоненты)
- **Animation**: Framer Motion (для сложных анимаций)
- **Icons**: Lucide React

### 4.2 Производительность
- First Contentful Paint (FCP) < 1.5s
- Time to Interactive (TTI) < 3.5s
- Lighthouse Performance Score > 90

### 4.3 SEO
- Мета-теги (title, description, keywords)
- Open Graph теги
- Семантическая HTML-разметка
- Оптимизированные изображения

### 4.4 Адаптивность
- Desktop (1280px+)
- Tablet (768px - 1279px)
- Mobile (< 768px)

### 4.5 Доступность
- Контрастность текста WCAG AA
- Keyboard navigation
- ARIA-атрибуты для интерактивных элементов

## 6. Контент

Все тексты должны быть:
- На русском языке
- Продающими, но без агрессии
- Чёткими и конкретными (без "воды")

### 6.2 Логотип
- SVG-формат
- Масштабируемый (разные размеры)
